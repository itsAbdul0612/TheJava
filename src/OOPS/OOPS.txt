iN OOPS (Object-Oriented Programming System) we deal with classes and objects, there are four principles of OOPS:

1. Encapsulation - Hide Data, Expose Behavior:

    Encapsulation is bundling of data AND behavior in a single unit which is often a class. This unit also hides the internal state of the data from the outside world and only exposes a controlled interface for interacting with it. This prevents any accidental modification of Data and allows easier maintenance and modification of code.

2. Inheritance - Reuse Code;

    Inheritance let one class (child class) inherit properties from other class (parent class), this promotes code reusability, helps build hierarchy and reduce duplication. Example: Class BankAccount is extended by Class SavingsAccount, as savings account is a type of bank account it will have the properties from a normal bank account (from BankAccount Class) as well as its own exclusive properties.

3. Polymorphism:

    Polymorphism in Java means methods with same name can behave differently. It has two types...
        1. Method Overloading: methods with same name having different method signature (no. of parameters, name).
        2. Method Overriding: methods with same name behaving differently, Example an inherited method doing something other than what it does in the parent class.

4. Abstraction
